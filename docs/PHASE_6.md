# 第六阶段：联调、验收与上线准备

第六阶段冻结 NEXORA V1.0 的业务范围，不再增加大型模块。本阶段完成双应用、统一数据库、权限、库存、订单、售后、采购、POS 与经营财务的发布前收口。

## 已完成

- 重新核对 System Specification、核心 ER 图及三条业务流程图。
- 运行内部端与顾客端现有自动化测试、类型检查、Lint 和双构建基线。
- 审计 Supabase RLS、公开视图、函数 `search_path`、函数执行权限、Storage、金额/时间类型、库存余额及流水一致性。
- 为管理端和商城增加部署环境门禁，阻止 Preview 连接生产 Supabase，阻止公开变量使用 secret/service_role key。
- 将关键入库 RPC 的原始数据库错误转换为中文安全提示。
- 增加审计日志与库存流水不可更新/删除的数据库迁移及元数据验收 SQL。
- 建立 A01–A16 可追溯验收矩阵、发布/回滚手册、岗位手册、GDPR 数据治理及 Day 1/Week 1 运行清单。

## 发布原则

- 代码完成不等于生产上线。生产迁移、域名切换、真实数据初始化和 Netlify Production Deploy 均需要单独授权。
- 自动化通过不替代真实手机、平板、仓库网络、打印/扫码设备与岗位用户的 UAT 签字。
- 真实支付、承运商、邮件、短信、税控收银和法定会计仍是外部集成，不得显示为已真实执行。

详细结论见 `docs/final_release_readiness.md`。
