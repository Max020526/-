# 第4阶段：快速入库与原子事务

- 新增 `/inbound/new` 手机优先快速入库页，员工只需填写款号、颜色和数量。
- 款号自动去空格并转大写，数量限定为1至99999，颜色来自启用中的字典。
- 同款可连续添加多个颜色，提交前显示款色数量与总件数。
- `confirm_inbound_order()` 在一个数据库事务中完成编号、商品、SKU、库存、单据、流水与审计日志。
- 商品不存在时自动建立 `PENDING_DETAILS` 主档；已存在商品或SKU只增加库存。
- 同款同色自动合并，库存行按固定顺序锁定，幂等键防止连续点击重复入库。
- SKU均码格式为 `款号-颜色代码`，未来增加具体尺码时可追加尺码代码。
- 已在线上 Supabase 通过真实管理员身份完成5件合并入库与重复请求回滚验证。
